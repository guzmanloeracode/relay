Relay · event delivery

Relay takes events from your application and delivers them as signed webhooks, emails and push notifications. It retries for a day, keeps what fails in a dead-letter queue you can replay, and logs every attempt.

API reference OpenAPI 3.1 Source code Status

What it does

  • Ingest with POST /v1/events: API keys, an Idempotency-Key, validation, and a 202 in milliseconds.
  • Route each event to the tenant's subscribed endpoints: webhooks, email and Expo push.
  • Sign webhooks with HMAC-SHA256 and a timestamp (Standard Webhooks), with a 10-second timeout.
  • Retry 8 times over up to 24 hours with exponential backoff and jitter, then dead-letter for manual replay.
  • Protect tenants from each other with token buckets and concurrency slots, so a slow endpoint can't starve the rest.
  • Observe through the delivery log API, Prometheus metrics, OpenTelemetry traces and JSON logs.

Send an event

curl {{.URL}}/v1/events \
  -H "Authorization: Bearer $RELAY_KEY" \
  -H "Idempotency-Key: order-1042-paid" \
  -d '{"tenant":"acme","type":"invoice.paid","payload":{"invoice":"INV-1042"}}'
